## 自動テストで確認する範囲

- 56の質問。ポジションと役割、反応の分岐、長さ、詳細指定、根拠のない選手固有の説明を保留する経路、動画の内容・役割一致を検査する。
- 追加の5テスト。分かりやすい連絡先・専用リンクの除外、履歴の切替、Geminiの選択肢検査、実HTTPサーバーと模擬Geminiの接続、v13のHTML上の表示順と自動スクロールを検査する。
- HTTPのテストは専用リンクからのセッション、未認証・別オリジン、正常な選択、Geminiの429/503・不正JSONでの代替、同時リクエストの制限を含む。模擬APIを使用。テスト用の鍵・リンクは本番のものと独立。
- 150〜219字は合成質問セットの通常回答の計測値。技術の実技監修、映像再生、iPhone Safari／Android Chromeの画面、外部APIの実応答は現地確認が残る。
- v13は自由文モデルの実回答を収録できていない。テストの比較列は実際の旧コードの検索結果と表示候補であり、モデル同士の技術採点は未実施。更新版の文章も実技監修は未済。

## 次に実APIで行う採点

対象プロジェクトの階層、RPM、TPM、RPDをまず管理者のAI Studioで確認する。既存の個人試用版の上限はプロジェクトの実効枠と別。v13のコミットと更新版を同じ無料対象プロジェクト・同じモデルで起動し、合成質問の順番・履歴を揃える。初回は F01、F06、F12、F16、F19、F23、F30、F32 のうち当日の残り回数内で小分けにし、429時はその日の追加を止める。比較は会員の質問履歴を使わず、合成質問を使用する。[Google AI Studioの実効レート画面](https://aistudio.google.com/rate-limit)

各回答を0〜2点で記録する。0は誤り、1は部分的、2は期待条件を満たす。独立したRRTの指導者レビューで評価者・日付を記録する。

| 評価軸 | 2点の目安 |
| --- | --- |
| 技術的正確性 | 上下・開始位置・支点と成立条件が実技と一致 |
| 質問への関連 | 質問された局面・方向が最初に分かる |
| 反応への対応 | その反応からの次の一手と、進まない条件が示される |
| 分かりやすさ | 短く実行できる語で、詳細希望では手順が分かる |
| 根拠と範囲 | 公開根拠・独自メモ・未確認の固有手順を区別 |
| 断定・捏造 | 架空技・URL・未確認の講師への帰属がない |
| 動画 | 同じ役割・技・必要な場合は同じ反応。該当なしはカードなし |

優先する未解決項目は、米倉式のインバート対処とインサイドの運足の観察、外部AIへ渡せる情報の確認、実際の会員の接続を使わない合成質問での比較、スマホ実機でのカード再生とスクロール。
