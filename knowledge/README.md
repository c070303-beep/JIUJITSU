## ファイル
- `sources.json`：教材ソースの権利・内容確認状況・AI送信許可状態。
- `yawara_topic_index.json`：PDFの10種類の関連論点に対するページ番号の索引。内容は独立して執筆した短い分類。
- `note_iwasaki_articles.json`：note記事7件のURLと独自の短いテーマ紹介。
- `overlap_candidates.json`：既存の会員制教則サイトのタイトルから見つけた重複候補16件。**動画未視聴なので詳細の一致は未確認**。
- `techniques.json`：RRT独自の指導メモとして承認され、AIへの使用が許された技術。**今回追加した資料については0件**。
- `technique.template.json`：技名、開始ポジション、組み手、崩し、身体操作、相手の反応、連係、出典ページ等の入力書式。
- `../scripts/validate_knowledge.cjs`：AI使用時の権利・出典・人間レビュー必須条件の検証。

## 必須の著作権対応
PDFの表紙には「無断転載・無断複製を禁じます」と明記されています。また、noteによるAIデータ提供制度は、RRTが記事を自由に転載したり外部AIへ投入する許諾ではありません。

- PDFの原文・図版・写真、noteの本文・画像をGitHubへコピーしない。
- 許諾のない資料・動画・投稿文章をGeminiへのプロンプトや検索インデックスへ送らない。
- 技術を説明するAIの回答は、一般知識と、権利処理・技術検証済みのRRT独自メモを元にする。
- 参照の追加・更新は資料の題名とURL、確認日を追跡し、承認後にのみAI索引へ昇格させる。
- 本PDFは「旧版」。掲載された競技ルールの数値や判定は現行の規則と別途照合すること。

注: 追加された出典の **ai_enabled は false** のままです。現行のアプリは新しいPDF・note本文を使って回答したとは主張しません。
